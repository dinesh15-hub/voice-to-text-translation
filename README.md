# 🎤 Voice-to-Text Translation App

A Python-based app that captures voice input, translates it into another language, and plays the translated audio.

## 🔧 Features

- Captures voice input using the microphone.
- Recognizes speech with Google Speech Recognition.
- Translates text using Deep Translator (Google Translate).
- Converts translated text to audio using gTTS.
- Auto-plays the translated audio file.

## 🛠 Requirements

- Python 3.7+
- Libraries: `SpeechRecognition`, `gTTS`, `deep-translator`

Install with:

```bash
pip install -r requirements.txt
